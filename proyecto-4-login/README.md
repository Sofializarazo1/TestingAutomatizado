# 🧙‍♂️ Pruebas de Inicio de Sesión — Obra Social de Hogwarts

> Automatización de pruebas End-to-End (E2E) para el módulo de Login utilizando **Cucumber (Gherkin)**, **Playwright** y **TypeScript**.

---

## Requisitos Previos

Asegúrate de contar con lo siguiente en tu entorno local:
- **Node.js** (versión 18 o superior recomendada).
- **npm** (gestor de paquetes, incluido con Node.js).

---

## Instalación

Abre una terminal en la raíz del proyecto y ejecuta los siguientes comandos para instalar dependencias y los binarios de Playwright:

```bash
npm install
npx playwright install
npm test
